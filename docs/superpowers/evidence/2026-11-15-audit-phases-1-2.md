## What changed and why

1. **The hero poster had a header baked into it.** `scripts/poster.mjs`
   screenshotted the canvas element, which captures anything painted over it.
   It hid the wordmark and meta but not `.site-header`, so a bilingual-era
   header — including the removed Arabic label — flashed under the live header
   for ~300ms on every load, in production. The capture now hides the header,
   the trigger and the dialog, and the posters are regenerated.
2. **The wordmark was cut by the fold.** A negative `margin-block-end` dragged
   the baseline past the section edge; a pixel probe measured ink on the final
   viewport row at 390 and 1440. The drop is now zero and one spacing step
   (`--space-1`) of padding owns the clearance.
3. **The menu trigger parked on running copy.** It was fixed and always
   visible below 768px. It now hides while the page is read downward and
   returns on any upward movement; it stays available at the top on mobile and
   past 30% on desktop.
4. **Footer links were 34–41px wide.** Inline padding plus a compensating
   negative margin on the list keeps the text on its column while every target
   clears 44×44.
5. **The home work chapter was 3,671px at 1440.** It is now a two-row spread
   (1,965px): a wide feature beside a smaller companion, then a balanced inset
   pair. The layout table covers the configured six projects.
6. **The contact disc was top-heavy.** `content-center` packs the label and
   arrow as one centred block.
7. **The home chapter jumped from 01 to 06.** The work chapter now carries 02,
   and the archive link gained an arrow.

## Follow-up (commit `51d09d4`)

**Reported:** the ghost header still appeared when navigating to `/` from
another route, and on first open.

**Root cause:** not a code regression. The regenerated files on disk were clean
(a fresh browser context showed no ghost), but the poster URL never changed, so
an already-open tab kept serving the old frame from its image cache — client
side navigation reused the same URL within the same document. The old frame is
the only place the removed Arabic label still exists.

**Fix:** `scripts/poster.mjs` now writes a content hash to
`src/content/poster-version.ts`, and every poster URL (`<source>` and `<img>`)
carries `?v=<hash>`. New bytes always produce a new URL, so a warm cache cannot
outlive a regeneration. One reload is still needed for tabs opened before this
commit.

**Also changed:** the hero shows the wordmark only. "Available for work",
"Scroll" and "Cairo, Egypt" are removed from the hero; availability and
location remain in the intro chapter, which already repeated them. The pulse
and scroll-cue keyframes are deleted with their last consumer.

**Verification:** 50 Playwright tests pass (2 new: hero carries the wordmark
only; every poster URL is versioned), 42 Vitest tests pass, typecheck/lint/build
exit 0. Evidence Gate re-ran with AC-10 and AC-11 added: PASS.
